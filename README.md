# M&I QuotePilot Lite

Versión ligera y sin costo fijo de M&I QuotePilot para validar ventas antes de pagar infraestructura.

## Incluye
- Landing responsive en español
- Estimador de rango de precio funcional en navegador
- Planes Solo ($39/mes), Pro ($79/mes), Agency ($149/mes)
- CTA para programa piloto
- Marca M&I Inspire Design

## Próximas integraciones
1. Publicación gratuita (Vercel o GitHub Pages)
2. Tally para captura de prospectos y onboarding
3. Calendly para reserva de citas
4. Stripe Payment Links para suscripciones

## Importante
El estimador produce referencias orientativas. El proveedor debe revisar y confirmar cualquier cotización final.
